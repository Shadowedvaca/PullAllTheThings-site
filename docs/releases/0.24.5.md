# Pull All The Things 0.24.5

## Highlights

- Pause scheduled automatic changes to website player ranks and Discord guild
  rank roles while issue #51 investigates stale rank data.
- Coordinate Development and Test deployments with other applications on their
  shared hosts through one bounded host lock.

## Fixes/Changes

- Remove rank reconciliation from both the scheduled Blizzard and Discord sync
  pipelines. Member and roster ingestion, integrity checks, and mismatch
  detection continue. Explicitly requested manual role corrections remain
  available.
- Add repository-owned shared-host admission around deployment preparation and
  activation, with disk, swap, and memory headroom checks before mutation.
  Production remains on its dedicated host.

  `ddfb1747b58243322b437417a339001d6a7fa859`.
- PR #83 passed the hosted quality gate at
  `2b164a89c0cd36df5d508e727be0a3595d5ad091` for the shared-host
  deployment changes.
- A scheduler regression check protects both scheduled pipelines from invoking
  rank reconciliation while retaining mismatch detection. Release, readiness,
  deployment-control, compile, and patch checks passed locally for PR #89.

## Deployment/Migrations

- No database migration is included. Development and Test use the standard
  `flock` utility and their existing 2 GiB swap configuration; no host helper
  is installed.
- The rank pause takes effect only after the approved Production deployment of
  this version. Existing roles and player ranks are not changed by deployment.

## Rollback

- The prior successfully deployed tag can restore the previous code if needed,
  but doing so re-enables scheduled rank reconciliation. Review that risk and
  manually supervise rank roles before a rollback.
- Reverting the repository-owned shared-host admission removes PATT's
  participation in the host lock; no server-side helper needs removal.

## Known Limitations

- Automatic website player-rank and Discord guild rank-role changes remain
  paused until issue #51 establishes authoritative rank data and verifies both
  promotion and demotion. Officers must review mismatches manually.
